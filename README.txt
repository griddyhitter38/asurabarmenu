ASURA SUSHI — EXACT PDF MENU WEBSITE

This version displays the original menu pages as images, preserving the original text, spelling, prices, order, layout, and design without retyping or editing anything. The original PDF is also included.

TO PUBLISH FOR FREE:
1. Upload the entire folder contents to a static hosting service, such as Netlify Drop: https://app.netlify.com/drop
2. Open the published website URL on an iPhone to check it.
3. Create a QR code pointing to that URL.

The site is designed for phone screens and uses no server/database. The noindex/nofollow tag asks search engines not to index the page, but it does not make the URL private. Anyone with the URL can open it.

TO UPDATE THE MENU:
Replace the page images in the pages folder with new exports from the updated PDF, keeping the same filenames, and replace original-menu.pdf. Do not edit the original content if exact fidelity is required.
